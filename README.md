## I build systems where capital meets code

I’m Kristian, a protocol engineer and forensic accountant (`CrFA` · `CFC`) with a BS in Management Accounting. I work across smart contracts, treasury automation, Web3 applications, and on-chain security.

The goal is straightforward: design the transaction path, instrument the system, and keep enough evidence to explain what happened after it ships. That means smart contracts where a rounding error is a liability, treasury automation where every flow is auditable, and monitoring that makes failures visible while they are still actionable.

> **Available for** protocol engineering, security reviews, and DeFi build or advisory engagements.

## What I work on

- **Protocol and smart contracts:** Solidity systems for yield, launchpads, bonding curves, account modules, and Safe modules.
- **Treasury and automation:** On-chain corporate treasury, zero-balance sweeps, Just-In-Time OpEx funding, and n8n/Xero financial workflows.
- **Security and forensics:** Threat modeling, on-chain monitoring, smart contract review, forensic accounting, and investigation.
- **Full-stack delivery:** Next.js and React dashboards, Web3 frontends, TypeScript services, and the infrastructure around them.

## Selected work

### [Zero-Balance Corporate Sweep Module](https://github.com/kristianism/zero-balance-sweep-module)

A Safe module that moves idle ERC-20 operating balances into Aave V3 and returns exact shortfalls for planned payments. The design includes Safe-authorized JIT intents, bounded relayer execution, sweep and JIT caps, cooldowns, wiring validation, and Safe v1.4.1 integration tests.

`Solidity` `Foundry` `Aave V3` `Safe` `ERC-6900` `Corporate Treasury`

<sub>Reference implementation with an internal security review. It has not received an independent professional audit.</sub>

### [Discord to n8n Bridge](https://github.com/kristianism/discord-n8n-bridge)

A persistent TypeScript service that holds a Discord Gateway connection, normalizes created and edited messages into a stable JSON envelope, and delivers them to n8n. It includes allowlisted routing, bounded concurrency, retry and backoff handling, idempotency keys, graceful shutdown, and redacted logs.

`TypeScript` `Node.js` `Discord Gateway` `n8n` `Docker`

### [DeFi Yield Farm](https://github.com/kristianism/defi-yield-farm)

A Solidity yield-farming template with a configurable ERC-20 reward token, pool management, emission controls, pending-reward views, emergency withdrawals, and transparent reward-rate updates.

`Solidity` `DeFi` `MasterChef` `Yield Farming` `OpenZeppelin`
